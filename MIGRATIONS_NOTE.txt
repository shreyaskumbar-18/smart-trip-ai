SmartTrip AI database note

The project uses one canonical Django database configuration. MySQL is the default and DB_NAME defaults to smarttrip. The package does not include a local database file or private data dump.

The Django migration files define the schema, including email verification, learned preferences, OTP verification, reviews, ratings, trip optimization and group planning.

Before applying migrations to an existing database, back up the database and inspect its migration history. Then run:

python manage.py migrate
python manage.py seed_data

The seed_data command loads the demonstration destinations and attractions. Set DB_ENGINE=sqlite in .env only if you want a separate local SQLite development database.
